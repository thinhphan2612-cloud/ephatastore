```
EPHATA ebooks is a Win32 desktop app (Tauri/Rust + WebView2) packaged as MSIX with entry point Windows.FullTrustApplication, so runFullTrust is needed for it to run. It is used only to open e-books the user picks, save exports/backups where the user chooses, keep library data in its AppData folder, store the license token in Credential Manager and call www.ephatastore.com over HTTPS to activate a license. No elevation, services, drivers or startup tasks.
```
