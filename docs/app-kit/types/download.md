# Loại 1 — Tải về

File người mua tải về máy và dùng: PDF, DOCX/XLSX/PPTX, ảnh, bộ thiết kế (.zip).
Trên admin chọn thẻ **Tải về**. Loại sản phẩm trong form: **Tài liệu tải về** (bộ thiết kế, template, tài liệu) hoặc **Hình ảnh**.

## Dùng khi
- Sản phẩm là **nội dung tĩnh**: giáo án, bài giảng, biểu mẫu, sách nhỏ, bộ ảnh, file thiết kế Canva/PSD/AI, slide.
- Người dùng mở bằng phần mềm có sẵn (Word, trình đọc PDF, Photoshop…), không cần chạy code của bạn.

Không phải loại này nếu: cần tương tác hay tính toán (→ Chạy trên store), cần cài đặt (→ Phần mềm bán key).

## Sản phẩm giao cho Ephata
- **Đúng 1 file** cho mỗi sản phẩm. Nhiều file → nén thành 1 `.zip` (thư mục gọn gàng + file `HUONG-DAN.txt` nếu cần).
- **Ảnh bìa** 16:9 (vd 1600×900), PNG/JPG/WebP, tối đa 5MB.
- **Logo vuông** + tối đa **4 ảnh / video minh họa** (ảnh ≤ 10MB, MP4/WebM ≤ 50MB hoặc link YouTube) — xem README, mục "Quy ước chung". Tài liệu: ảnh chụp vài trang mẫu là minh họa tốt nhất.
- **Mô tả**: nội dung có gì, dành cho ai, định dạng file, số trang/số mẫu, cần phần mềm gì để mở.

## Yêu cầu kỹ thuật
| Mục | Yêu cầu |
|---|---|
| Tên file | **Không dấu, không khoảng trắng** (vd `giao-an-mua-vong-2026.pdf`). Ký tự ngoài `a-z A-Z 0-9 . _ -` bị đổi thành `_`. |
| Dung lượng | Tối đa **50MB** / file (trình duyệt tải thẳng lên kho lưu trữ). |
| PDF | Nhúng font (Export → PDF/A hoặc "Embed fonts"), để in đúng trên mọi máy. |
| DOCX/PPTX | Dùng font phổ biến có tiếng Việt (Arial, Times New Roman, Roboto…) hoặc nhúng font. |
| Ảnh | ≥ 2000px cạnh dài nếu bán để in; ghi rõ kích thước trong mô tả. |
| Bản quyền | Chỉ bán nội dung bạn sở hữu hoặc có quyền. Bản dịch Kinh Thánh, sách lễ, nhạc thánh ca thường **có bản quyền** — kiểm trước khi trích dùng. |

## Giá & quyền
- Khung **Bán** trong form: **Miễn phí** (ai đăng nhập cũng nhận) hoặc **Có phí — mua 1 lần, dùng vĩnh viễn** (giá VND,
  người mua trả bằng point, 100đ = 1 point). Có ô **Giá gốc** nếu đang giảm giá.
- Ô **"Miễn phí cho tài khoản Pro Giáo Lý Số"**: tick thì tài khoản Pro tải miễn phí **trong thời gian gói Pro còn hạn**; không tick
  thì ai cũng mua. **Full Topping** cũng tải được sản phẩm có phí.
- Người mua tải qua link ký có hạn 24 giờ (link tạo mới mỗi lần bấm Tải về ở Thư viện); chưa mua thì không tải được.

## Đưa lên admin
1. **Admin → Thêm sản phẩm → Tải về**.
2. Điền tiêu đề, slug (để trống = tự tạo; tiêu đề toàn emoji / ký hiệu thì phải nhập slug), loại Tài liệu tải về / Hình ảnh,
   mô tả ngắn + chi tiết, danh mục, nhà phát hành.
3. Khung **Bán**: Miễn phí / Có phí + giá + ô Pro Giáo Lý Số.
4. Tags, ảnh bìa, mục **Giao hàng** → chọn file tải về (bắt buộc nếu tick **Đang bán** — chưa có file thì để nháp). Tick
   **Đang bán** + **Hiện trên store**. Bấm **Lưu** (chờ thanh tiến trình tải xong).
5. Bản mới: mở **Sửa** sản phẩm → chọn file mới → Lưu. **File cũ bị xóa ngay** — người đã mua tải bản mới (không giữ bản cũ).

## Kiểm sau khi lên
- Mở trang sản phẩm: giá hiện đúng ("… point · vĩnh viễn"), nút Mua đúng số point. Store đang bật Coming Soon thì khách đăng xuất
  chỉ thấy trang "Sắp ra mắt" — kiểm bằng tài khoản admin.
- Bằng tài khoản admin: mua/nhận → **Thư viện** → **Tải về** → file mở được, đúng tên.
